Privacy policy – Eigenframe Studio

Last updated: 12 October 2026

Eigenframe Studio is a private publishing tool used only by its operator for the operator's own YouTube channels.

What it accesses

With the operator's consent it uses Google OAuth scopes youtube.upload (to upload approved videos) and youtube.readonly (to confirm which channel it is connected to and read upload status).

What it stores

An OAuth refresh token and the connected channel ID, stored on the operator's own server with owner-only file permissions. It does not store passwords and does not collect data about viewers or other people.

Sharing

No data is sold, shared or transferred to third parties. Google user data is used only to provide the upload function described above, in line with the Google API Services User Data Policy, including its Limited Use requirements.

Removal

Access can be revoked at any time at myaccount.google.com/permissions; after that the stored token no longer works, and the operator deletes it from the server.
